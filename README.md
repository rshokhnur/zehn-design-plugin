# zehn-design: Claude Code plugin

Keeps the dev team's AI coding agents on the zehn design system. The Figma file `zehnmind` is the source of truth.

## What it does
| Part | What happens |
|---|---|
| **SessionStart hook** | Every Claude Code session starts with the zehn hard rules, which skill to use when, and how to handle off-system requests. |
| **`compose-screen` skill** | New screens, flows, modals, drawers: from a Figma link (via the Figma MCP) or composed from existing patterns. Full UI/UX rules, component catalog and token cheat sheet. Ends with a "Design gaps" list for the designer. |
| **`ui-tweak` skill** | Small changes to an existing screen, with a short rules card instead of the full catalog. |
| **`ui-review` skill** | Checks a branch or files against the rules and fixes what it can. |
| **`setup-tokens` skill** | Installs tokens, the Tailwind preset, Inter, Remix icons, the shared React components, or the Swift/Dart/Kotlin theme file. |
| **Style check (after each edit + before finishing)** | Checks only the lines the agent changed (also via Bash) for hex/rgb/named colors, Tailwind default palette and dead classes, arbitrary `[..]` values, off-scale spacing/radius/type, extra font weights, non-Inter fonts, unknown `--zm-*` tokens, and Swift/Dart/Kotlin equivalents. |

## Install (each developer, once)
From GitHub (needs read access to this repo):
```
/plugin marketplace add rshokhnur/zehn-design-plugin
/plugin install zehn-design@zehn
```
From a zip: unzip to a permanent folder (e.g. `~/zehn-design-plugin`), then:
```
/plugin marketplace add ~/zehn-design-plugin
/plugin install zehn-design@zehn
```
Then, in each app repo, run once: "use the setup-tokens skill".
For the live Figma part, connect the Figma MCP in Claude Code (works with a Dev Mode seat).

## Update
Devs: `/plugin marketplace update zehn` (zip users: replace the folder first), then re-run `setup-tokens` in their apps.
Designer, after Figma changes: re-export the variables to `tokens/source/figma_vars.json`, run `python3 scripts/gen-tokens.py`, edit `reference/*.md` if rules changed and run `scripts/build-skill.sh`, run `node tests/check-ui.test.js`, bump `version` in `.claude-plugin/plugin.json`, push.

## Upgrading from 0.2
- Web cards, panels, tables, toasts and badges use 4px corners (`rounded`), as in Figma. Badge tinted fills, Switch (cyan when on) and Toast (white card) now match the Figma components.
- New components: `HeaderPattern`, `RoleBanner`, `ZehnLocaleProvider` (en / ru / uz labels) and `format*` helpers (dates, money, numbers, durations). Re-run `setup-tokens` to copy them in.
- New layout tokens: `h-chart-card` (334), `h-chart-plot` (208), `w-toast` (432).
- The style check also flags raw `<button>`/`<select>`/`confirm()` in app code, `!important` overrides, and named colors inside shorthands.

## Upgrading from 0.1
- Tailwind spacing now uses the **standard Tailwind keys** (`p-4` = 16px). Code written with 0.1's pixel keys (`p-16`, `gap-12`) must be converted (`p-4`, `gap-3`). The style check flags the off-scale ones (`p-20`, `gap-40`), but `p-16`, `gap-12`, `p-24` etc. stay valid and silently grow 4×, so search for them.
- Radius classes are now `rounded` (4), `rounded-lg` (8), `rounded-xl` (12), `rounded-2xl` (16), `rounded-full`; `rounded-4/8/12/16` are flagged.
- The preset file is now `tailwind.preset.cjs`; delete the old `tailwind.preset.js` copy.
- Button/IconButton use `variant` (not `style`); Badge uses `appearance` + `color`/`status`; Counter uses `tone`.

## Files
- `reference/*.md`: human-readable rules, catalog and token sheet. Edit these, then run `scripts/build-skill.sh` (it inlines them into compose-screen).
- `tokens/`: generated by `scripts/gen-tokens.py` from `tokens/source/figma_vars.json`. Don't hand-edit.
- `components/react/`: shared React + Tailwind components, copied into apps by `setup-tokens`.
- `scripts/check-ui.js`: the style checker (also a CLI: `node scripts/check-ui.js src/**/*.tsx`). `tests/check-ui.test.js`: its regression cases.
- Escape hatch: `zehn-ignore: requested by <who>, <why>` on a line skips it; every one must be listed as a design gap.
